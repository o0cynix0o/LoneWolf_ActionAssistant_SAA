# Design assets

`series-sigil-wolf-source.png` is the original image-generation output selected
by the repository owner for the application's series divider on 2026-07-27.
It was created during the project's sigil-design session and approved for use
in this application.

The shipped `assets/images/series-sigil-wolf-mask.png` is a luminance-derived,
transparent mask of that source. The application colors the mask with the
active theme accent. The original stays here for design provenance and is not
included in the packaged runtime.
