# Documentation Audit: 3.5.0 Internal Testing

## Scope

This audit reviewed the repository README, changelog, player guide, build and
release guides, series audits, historical handoff reports, and the separately
versioned SAA wiki.

## Current Player-Facing Boundary

The live documentation now consistently describes Books 1-29 as playable
internal-testing campaigns:

| Series | Books | Entry model |
| --- | --- | --- |
| Kai | 1-5 | Book 1 creation and campaign continuation |
| Magnakai | 6-12 | Fresh setup or continued Kai campaign |
| Grand Master | 13-20 | Fresh setup or continued Magnakai campaign |
| New Order | 21-29 | Fresh setup or continued New Order campaign |

Book 20 ends the original Grand Master campaign. Book 21 starts a different
New Order Kai Grand Master, so no direct character handoff is offered.
