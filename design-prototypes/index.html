UI redesign studies

One campaign. Four useful shapes.

Each direction uses the same current campaign: Book 6, The Kingdoms of Terror, at section 219. The goal is to choose the right structure before changing the live application.

Reading

The campaign is the anchor.

The primary action in every study is Start Current Campaign, not an ambiguous reader or resume command.

A. Campaign Desk
Reading

A practical desktop command centre. It keeps campaign state, active tools, and a compact series path within reach.

  • Strong all-purpose candidate
  • Dense without looking terminal-like
  • Best for active play and testing
Open Campaign Desk
B. Reader First
Reading-focused

The book is the main event. Decisions and story remain calm and legible while the assistant stays nearby.

  • Maximum reading space
  • Focused choice handling
  • Tools never crowd the page
Open Reader First
C. Library Command
Collection-focused

A campaign library that makes all 29 books comprehensible while preserving one obvious place to continue.

  • Best series navigation
  • Clear book status and readiness
  • Good home for importing and testing
Open Library Command
D. Combat Mode
Encounter-focused

A temporary combat state that gives the fight, the next round, and the outcome priority over general bookkeeping.

  • One live encounter state
  • Round controls lead the page
  • Outcome replaces the duplicate Start action
Open Combat Mode
