Install The Books

Lone Wolf Action Assistant does not include the Project Aon book files. Download the standard multi-page HTML ZIPs from Project Aon for your own personal use, then import them into this app.

Home Assistant Project Aon License

Import Your Books

Import one or more downloaded ZIPs, or select a folder containing already-extracted books. Files are validated and copied into the app's managed books folder.
